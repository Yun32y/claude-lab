# 2027 清邁旅遊｜6天5夜自由行

線上版：https://chiangmai-travel-2027.vercel.app/

一個單頁式的行前資訊網站，提供給一起去清邁自由行的朋友們查看行程資訊，並填寫行程願望清單調查表單。

## 功能

- **清邁自由行前準備**：簽證、TDAC 數位入境卡、換匯、保險、交通、插座電壓、防曬防蚊、退稅等懶人包
- **航班與天氣**：各航空公司去回程班表比較、1 月天氣與穿搭建議
- **區域解析**：尼曼區、夜市區、古城區與塔佩門、周邊郊區、湄登區、其他一日遊行程，各區代表景點與連結（連結皆有底線＋外部連結箭頭圖示，手機上不需 hover 也能辨識）
- **市集指南**：依星期分類的市集營業時間表
- **願望清單表單**：姓名、航班偏好、住宿類型（單選）、預算、交通偏好、想去的景點（依區域分類複選，可勾選「交由里長安排」直接跳過景點挑選，下方選項會自動停用並灰化）、最早出發時間、飲食禁忌、其他需求，送出後即時顯示摘要，並將回覆送到 Google Sheets
- **進站背景音樂**：可播放／暫停的背景音樂按鈕
- **視覺設計**：日落色系配色（奶油杏／珊瑚橘／灰藍／深石墨），航班與市集標籤統一淺色底＋深色字，避免深淺不一導致的對比度問題

## 使用技術

純 **HTML / CSS / JavaScript**，沒有使用任何框架或建置工具，`index.html` 單一檔案包含所有樣式與邏輯，`assets/` 資料夾放圖片、動圖與音樂。表單資料透過 `fetch` 送到 Google Apps Script 網頁應用程式端點，寫入 Google Sheets。

## 如何用瀏覽器開啟

**方法一：直接開啟檔案**

直接用瀏覽器打開 `index.html` 即可預覽（部分瀏覽器可能會限制 `file://` 協定下的功能，建議用方法二）。

**方法二：啟動本機伺服器**

```bash
cd chiangmai-travel
python3 -m http.server 8000
```

再用瀏覽器開啟 http://localhost:8000 即可。

## 部署注意事項

正式網址是靠這個資料夾內連結的 Vercel 專案（`chiangmai-travel-2027`）用 CLI 手動部署的，**不是**靠 push 到 `claude-lab` 這個 GitHub repo 的 main 分支自動觸發。修改完 `index.html` 後，除了照常 commit／push 留存版本紀錄外，一定要額外執行：

```bash
cd chiangmai-travel
npx --yes vercel deploy --prod --yes --scope yun32y1
```

才會真的更新 https://chiangmai-travel-2027.vercel.app/ 上線的內容。
